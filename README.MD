
# Jonas Hinterdorfer

Full-stack developer from the Bezirk Scheibbs, Lower Austria. Currently finishing an HTL diploma thesis on a 3D measurement application, and building things with .NET, Angular and Kubernetes in between.

## What I'm doing right now

- Writing my diploma thesis: a backend/frontend system with a 3D-camera measurement pipeline
- Working with .NET, Angular, PostgreSQL, Elasticsearch and Keycloak day to day
- Running everything on Docker, Kubernetes and Traefik on a small self-hosted setup
- Slowly getting into machine learning basics and depth/image processing for the vision side of the thesis
- Off-screen: trail riding, 3D printing and modeling, and way too much Hypixel SkyBlock
